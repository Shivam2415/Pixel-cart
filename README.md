# LensCraft

LensCraft is a responsive image discovery web application built using plain HTML, CSS, and JavaScript.

## Features & Design Decisions
1. **Category Quick-Pick Chips:** Added clickable category chips (Nature, Cities, Animals, Minimalism) below the search input so users can explore popular search topics with a single click.
2. **Empty-State Message:** Included an initial prompt ("Type a topic above and search to discover images!") to guide first-time visitors before any query is entered.
